# Metric Conversion

A simple Android application for converting between different units of measurement.

## Features

This app allows you to convert:

*   **Distance:**
    *   Miles to Kilometers
    *   Kilometers to Miles
*   **Temperature:**
    *   Fahrenheit to Celsius
    *   Celsius to Fahrenheit
    *   Fahrenheit to Kelvin
    *   Celsius to Kelvin

## How to Use

1.  Enter the numerical value you want to convert in the text field.
2.  Click the button corresponding to the conversion you want to perform.
3.  The result will be displayed on the screen.
